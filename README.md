# From April to November

This is a box of things I made with Claude in 2026, from April to November.

Most of them are small web pages. You can open any `.html` file in a browser and it just works. No setup.

## What is inside

### `artifacts/` — pages I made to learn and plan

**Study ladders.** A ladder is a set of practice steps. The first step is easy. Each step after it is a little harder. The last step is harder than the real test.

| File | What it is for |
|---|---|
| `c-exam-2-ladder.html` | Practice for my second C exam |
| `the-c-writing-ladder.html` | Learning to write C code by hand |
| `the-c-drill-deck.html` | Quick C drills |
| `pe1-ladder.html`, `pe2-ladder.html` | Practice for two programming exercises |
| `term-ladder.html`, `token-ladder.html`, `keyword-ladder.html` | Learning programming words |
| `calc-ladder.html` | Calculus practice |
| `math-1042-test-1-crash-course.html` | A fast review for a math test |
| `values-ladder.html` | Practice with values |
| `the-determinism-ladder.html` | A step-by-step guide |
| `n5-kanji-words.html` | Japanese words for beginners (JLPT N5) |

## How to use a page

1. Download the file.
2. Double-click it.
3. It opens in your browser.

Some pages remember your progress. They save it only in your own browser.
