H

Write it yourself

Reading C and writing C are different skills, and only one of them is tested by prediction questions. Each of these is ten minutes of work and forces a rule to become reflex.

H1

Seconds to clock time

Read a number of seconds into an int (hard-code it for now), then print it as hours, minutes and seconds. 3725 should print 1:02:05.

Every piece is one / or one %. No other operator is needed.

H2

The average that lies

Declare int a = 7, b = 2; and print their average two ways: once so it prints 3, and once so it prints 3.5. Same two variables both times.

The fix is a cast on one operand. Casting the result is too late — the damage happens during the division.

H3

Prove the division identity

For any integers a and b, (a/b)*b + (a%b) should equal a. Print both sides for a few pairs, including negative ones like −17 and 5.

This is why C defines % the way it does. The identity is the whole reason the remainder takes the left operand's sign.

H4

Break it on purpose

In one file, write each of these on its own line, compile, and read the error: 5 = x;   int 2nd = 4;   int double = 1;   ++x--;

Fix them one at a time. Learning to read gcc's error text is worth more than any single rule in this module.

H5

Trace before you run

Write a program with int x = 5; followed by six lines that each modify x with a different operator (+=, *=, %=, ++, -=, /=), printing x after each. Predict all six values on paper first, then run it.

If you got all six, you've finished this module. If you missed one, that operator is the one to review.
